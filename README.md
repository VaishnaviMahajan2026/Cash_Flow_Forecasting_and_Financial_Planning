# Cash Flow Forecasting and Financial Planning

## Project Overview
This project analyzes Apple's (AAPL) financial statements to understand cash flow, profitability, and financial performance over time.

## Objectives
- Analyze operating cash flow and free cash flow.
- Study net income and capital expenditure.
- Calculate and analyze cash flow margin.
- Visualize financial trends using Power BI.

## Tools and Technologies
- Python
- Pandas
- Financial Modeling Prep (FMP) API
- Microsoft Excel
- Power BI
- SQL

## Data Sources
Financial data was collected using the Financial Modeling Prep API, including:
- Cash Flow Statement
- Income Statement
- Balance Sheet

## Project Workflow
1. Fetch financial statement data using Python and the FMP API.
2. Store the data in CSV files.
3. Clean, process, and analyze financial data using Pandas.
4. Export the financial analysis to Excel.
5. Build an interactive dashboard in Power BI.

## Key Analysis
- Operating Cash Flow
- Free Cash Flow
- Net Income
- Capital Expenditure
- Cash Flow Margin
- Year-over-year financial trends

## Project Files
- `main.py` — Main Python script
- `import_to_sql.py` — SQL data import script
- `cash_flow.csv` — Cash flow statement data
- `income_statement.csv` — Income statement data
- `balance_sheet.csv` — Balance sheet data
- `Financial_Analysis.xlsx` — Financial analysis report
- `Cash_Flow_Forecasting_Dashboard.pbix` — Power BI dashboard
